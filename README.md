# WEB Proxy Panel

Панель управления и Telegram-бот для **Telegram WEB Proxy** на базе
[`telegramdesktop/tproxy-server`](https://github.com/telegramdesktop/tproxy-server)
и официального [`MTProxy`](https://github.com/TelegramMessenger/MTProxy).

> Проект в разработке. План реализации — [`PLAN.md`](PLAN.md),
> результаты проверки исходников — [`docs/FINDINGS.md`](docs/FINDINGS.md).

## Требования

- выделенный сервер x86_64, Ubuntu 22.04+ или Debian 12+, systemd;
- домен, A-запись которого указывает на сервер;
- открытые входящие TCP 80 и 443.

## Установка

Команда установки появится после этапа M5.
